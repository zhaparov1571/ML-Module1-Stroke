# Прогноз риска возникновения инсульта (Machine Learning)

Учебный проект по дисциплине «Машинное обучение» (Модуль 1). Цель проекта — построить модель классификации, которая на основе медицинских показателей предсказывает вероятность появления инсульта у пациента.

---

## 📂 Структура проекта
* `healthcare-dataset-stroke-data.csv` — исходный датасет с медицинскими данными.
* `Untitled0.ipynb` (или переименуй в `stroke_prediction.ipynb`) — Jupyter Notebook с полным кодом (предобработка, обучение модели, оценка качества).

---

## 🚀 Используемые библиотеки
Проект написан на языке **Python** с использованием следующих библиотек:
* `pandas` — для загрузки и очистки данных
* `scikit-learn` — для построения моделей машинного обучения и оценки метрик

---

## ⚙️ Ход выполнения работы (Пайплайн)
1. **Загрузка и осмотр данных:** Проверен размер датасета (5110 строк), изучены типы признаков.
2. **Предобработка данных:**
   * Удален ненужный признак `id`.
   * Пропущенные значения в колонке `bmi` заполнены средним арифметическим.
   * Текстовые категориальные признаки переведены в числовой формат с помощью `LabelEncoder`.
3. **Разделение выборки:** Данные разделены на обучающую (80%) и тестовую (20%) выборки.
4. **Обучение модели:** Использована классическая **Логистическая регрессия** (`LogisticRegression`).
5. **Оценка качества:** Получена общая точность модели (Accuracy ~93.9%), а также сформирован отчет о классификации (`classification_report`).

---

## 📊 Результаты
Модель успешно обучена и способна делать бинарные предсказания. В ходе анализа также выявлена проблема дисбаланса медицинских классов, что учтено при оценке метрик.
